# Decision Log — Flow Foundry

Non-obvious foundry calls, one file per entry: `YYYY-MM-DD-<slug>.md`, stamped `type: decision-log`. Earned by triage drops, security/license flags, structural choices, verified promotions (the review evidence itself), and mid-run deviations. Append-only. Shape and rules: `../../methodology/governance-and-audit.md` §5.

# harness/ — Context

## What this room is for

Emergent Hermes design material — the intelligence this prototype generates about itself. When using the Delivery Manager reveals something about how an agent should work, what it should know, or where the folder model breaks down, that insight belongs here. `harness/` is the room where the prototype studies itself.

This is distinct from `projects/hermes/`, which holds design and build work for the Hermes *stack*. `harness/` holds what the Delivery Manager's own usage teaches about what that stack needs to become.

## What lives here

- Observations about the routing model (what CLAUDE.md got right, what it got wrong)
- Notes on the CONTEXT.md files as they're revised from lived friction
- Patterns noticed while using the project that suggest agent architecture decisions
- Design insights that should flow into the Hermes Homelab Manager spec when this prototype migrates
- Schema evolution notes (e.g., if the `usage-trace` type earns a formal promotion, the argument for it starts here)

## What does NOT live here

- The Hermes stack design work itself (→ `projects/hermes/`)
- Synthesis findings (→ `synthesis/`)
- Traces of individual interactions (→ `traces/`)
- Finished architecture docs ready for corpus (→ `corpus/`)

## Process

Harness items are generated by noticing, not by scheduling. When something about the project's operation surprises you — a routing decision that felt wrong, a CONTEXT.md that didn't hold up, a capability that fired in an unexpected domain — write a short note here. It doesn't need frontmatter at capture time. It needs a date and a description.

Periodically, harness notes that have accumulated enough weight get promoted: either into a design decision in `projects/hermes/`, or into a proposal for the synthesis task to absorb, or into a revision of CLAUDE.md or a CONTEXT.md file.

## The meta-question this room answers

*What does this prototype teach about what a Homelab Manager agent actually needs to do?*

The answer is assembled here, piece by piece, from the friction and the surprising moments. When the prototype migrates, this room's contents are the design brief the Hermes stack inherits.

# Forge

## What this room is for
The build. Where a triaged starter becomes a house-standard skill — whether by transcribing clean intent (primer-brief) or reverse-engineering messy material (foreign starter). This is the longest-dwell room and where the foundry's real craft happens.

## Process
For a primer-brief: transcribe the decided intent into a skill — don't re-explore it.
For foreign material: extract the real intent (confirm against the actual material, don't trust its self-description), then rebuild.

Either way:
1. Build via the engine room — skill-creator's flow for structure and eval.
2. Author the SKILL.md in the house voice: identity, workflow, "What This Skill Is Not", references that point to canonical (never frozen copies), progressive-disclosure structure.
3. Stamp the two artifacts: clean SKILL.md (agentskills.io headers only) + companion DNA vault-doc (full block), truth-level: to-review.
4. Set execution-tier via the checklist (references/execution-tier.md).
5. Preserve origin for foreign skills in the vault-doc Connection Notes.
6. Log a trace stamped with the capability the skill embodies.

When intent is too thin to build well, stop and ask — or hand back to triage / the thinking-partner. Don't invent a skill from a fragment.

## What lives here
Work-in-progress skills. The finished pair moves toward /review-bench (and the work-product copy accumulates in /corpus). Drafts can sit here mid-build.

## What good looks like
A skill that reads as a sibling to the three pipeline skills — same voice, same boundary discipline. A foreign skill that no longer reads as foreign. Bad: a structurally-valid skill that doesn't sound like family, or one whose execution-tier was guessed rather than run through the checklist.

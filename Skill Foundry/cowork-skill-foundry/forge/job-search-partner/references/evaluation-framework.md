# Evaluation Framework — the five dimensions

Harvested from the source's `04-job-evaluation.md`, generalized for a two-person
household. Score each dimension 0–100 (except logistics, which is a gate), present
as a table, and give an overall verdict: **strong / moderate / weak fit**. The
strong/moderate/weak match *areas* for dimensions 1–2 come from the person's
career profile, not from this file.

## 0. Deal-breaker gate (before any scoring)

Check the posting against the profile's deal-breakers. Any hard violation
(relocation required, salary floor unmet where stated, excluded sector, schedule
conflict) → **FAIL, stop scoring, say which gate tripped.** Ambiguous cases
(e.g. travel "up to 25%") → FLAG and ask.

## 1. Technical skills match (0–100)

| 80–100 | Core requirements are primary skills |
| 60–79 | Most match; 1–2 learnable gaps |
| 40–59 | Partial; significant upskilling |
| 0–39 | Fundamental mismatch |

Name the gaps explicitly. "92 — but no Kubernetes, which they list as required"
is the house style; a bare number is not.

## 2. Experience match (0–100)

| 80–100 | Direct experience, same domain and role type |
| 60–79 | Related; transferable skills clear |
| 40–59 | Adjacent; the case must be made |
| 0–39 | Unrelated |

Below 50: warn before drafting (extensive reframing needed, and reframing has
limits — see writing-style.md).

## 3. Culture / environment fit (0–100)

Score against the profile's energize/drain section and optional self-assessment.
Research red flags before scoring, not after: team reviews, leadership signals,
maintenance-vs-development balance, reorganization news. Note what couldn't be
verified rather than guessing it positive.

## 4. Location & logistics (PASS / FAIL + notes)

Within commute or acceptable-remote → PASS. Relocation → FAIL (unless the profile
explicitly allows it). Heavy travel → FLAG for discussion. For a two-career
household, a logistics PASS for one person can still be a household question
(schedule collision, shared constraints) — note it when visible.

## 5. Career alignment & motivation (0–100)

Does the role advance where this person says they're going, with tasks from their
"energizes" list? A high-skills-match role made of draining work is a trap; score
it like one and say why.

## Verdict and the call-first suggestion

Overall verdict weighs all five, but gates and motivation can veto a high skills
score — say so when they do. When the posting names a contact person and the fit
is moderate-or-better, suggest the candidate call before applying: it sharpens
the letter and is a positive signal in many markets. (Source framework's advice;
keep it.)

# Decision Log — Skill Foundry

Non-obvious foundry calls, one file per entry: `YYYY-MM-DD-<slug>.md`, stamped `type: decision-log`. Earned by triage drops, vetting failures (especially security/license flags), boundary-collision resolutions, verified promotions (the review evidence itself). Append-only. Shape and rules: `../../methodology/governance-and-audit.md` §5.

# Completed — Skill Starters (DONE record)

Primer briefs (`sp-<slug>.md`) whose corresponding skill has cleared the
five-point human gate (`../foundry-spec.md` §5) and been promoted to
`../../produced-skills/`. This is the intake-record's terminal home — the
foundry's answer to "where did the primer brief for a finished skill end up."

Files here move here from `../backlog-skill-starters/` at the same moment the
operator promotes the built skill to `../../produced-skills/`, and their
`truth-level` is bumped to `verified` to match. Nothing moves out of this
folder — it is a historical record, not a working queue.
